# Python DSA

This repository contains my solutions to Data Structures and Algorithms problems solved in Python. I created it to practice problem-solving, strengthen my understanding of DSA concepts, and keep track of my progress.

Most of the problems are from LeetCode, with a few from other coding platforms.

## Repository Structure

```
Python-DSA/
│
├── Arrays/
├── Hashing/
├── LinkedList/
├── Numbers/
└── Strings/
```

Each folder contains problems related to a particular topic.
